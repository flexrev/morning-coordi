## 2. 구현 중 내린 결정 (요약, 상세는 data-conversion-log.md 3·4·7절)

- **포멀도 규칙 완화**: 차단 임계 5→6(4~5는 경고), 블레이저·트렌치·체스터필드 한 단계 하향, 출처 2개 이상 클래식은 차단 면제. 이유: "흰 티+카멜 트렌치", "흰 티+네이비 블레이저"가 리서치상 클래식인데 차단되고 있었음. universal 10→12 복원
- **변주 생성 버그 2건 수정**: 상의가 변주 5장을 독식하던 문제(슬롯당 2장 상한), 신발 색만 바꾸고 종류를 안 바꿔 "브라운 흰 스니커즈"가 나오던 문제
- **컴팩트 카드 캡션**: shortLabel 붙여쓰기("인디고데님") + 2줄 말줄임, S5 상세는 전체 캡션
- **엔진 결과에 `avoid[]` 추가**(정방향+역방향+포멀도 차단 품목) → S4 "피할 것" 행이 실데이터로 동작
- **성능 수용**: quick ≤2ms, deep ≤27ms. 목표 10ms 미달이나 체감 없음
