## 0. 방법과 한계 (Phase 4 와 동일)

- Chrome 155 헤드리스(CDP, 모바일 에뮬레이션 DPR 2, 터치) **375×812 / 360×780 / 390×844 / 430×932**, UA iPhone·Android. 좌표는 전부 `getBoundingClientRect()` 실측(CSS px). 탭은 `Input.dispatchTouchEvent` 로 세었고, 뒤로는 `history.back()`.

## 2. 발견 사항

심각도: **높음** = 아침 10초 경로를 늦추거나 오도, 또는 Phase 4 회귀 · **중간** = 눈에 띄는 마찰·설계 위반 · **낮음** = 다듬기

### U6-01 (높음) 오늘 카드 라벨이 360·375 에서 말줄임 — 번호가 안 보이고, 보여도 순서(2/3 → 1/3 → 3/3)가 읽기 순서를 깨뜨림
- 실측: `.card__labeltext` "오늘의 추천 · 클래식 2/3" 폭 **134px**, 가용 폭 360 에서 112 / 375 에서 127 → `text-overflow: ellipsis` (`03-s3-first-375.png`, `80-*`). 390·430 에서만 다 보임. 컴팩트 모드(360+바로가기 줄)에선 패딩이 줄어 역설적으로 다 보임(`74-s3-compact-360.png`).
- 다 보이는 폭에서도 문제: 세 장이 **2/3, 1/3, 3/3** 순으로 서 있어 "왜 2가 먼저지?"가 된다. S5 제목은 "클래식 2/3"(오늘 맥락 없음), 공유 이미지 라벨도 "클래식 2/3 · 봄가을". 즐겨찾기 라벨은 "하의 · 인디고 · 봄가을"(번호 없음)이라 번호를 기억할 이유가 애초에 없다.
- 제안 라벨(표시 순서 기준, `ref` 는 그대로 `classic.N`):
  - 오늘 카드: **`오늘의 추천`** (숫자 없음, 폭 ≈ 70px → 어느 폭에서도 안 잘림)
  - 나머지 두 장: **`다른 클래식 1/2`, `다른 클래식 2/2`** — "오늘 것 외에 둘 더" 가 한 줄에서 읽힌다. "클래식 2/3·3/3" 처럼 빠진 번호를 추측하게 하지 않음.
  - S5 제목·공유 라벨도 같은 문자열(`오늘의 추천 · 봄가을`, `다른 클래식 1/2 · 봄가을`). `findCandidate('classic.N')` 이 돌려주는 label 을 오늘 인덱스와 비교해 만들면 됨(`state.js`, `today.js`).
  - 클래식이 3장 미만·변주로 채운 날은 `오늘의 추천` / `변주`(현행).
- 보조: `.card__labeltext` 가 잘릴 때 "자세히 ›"(aria-hidden 장식)가 먼저 양보하도록 `.card__detail { flex: 0 1 auto; min-width: 0 }` + 라벨 `flex: 1 1 auto`.

### U6-02 (높음) 카드 60×118 일러스트에 그려진 액세서리가 옷을 잘못 읽게 함
- 본 것(`08-s3-cards-zoom-375.png`, `12-s4-tone`, `13-s4-style`, `50-s4-amekaji`): 백팩 끈 = **멜빵**(화이트 티 위 검은 두 줄, 인디고 클래식 1/3), 캡 = **파란 헬멧**, 스카프 = **빨간 넥타이**(클래식 3/3·톤별 5장 전부), 토트 = **서류가방/상자**(오늘 카드), 흰 토트 = 종이 한 장(톤별 2번). 양말·벨트는 작아서 거의 안 보임(해 없음).
- 왜 높음: 카드는 "무슨 옷인지" 0.5초에 읽는 자리다. 캡션 "화이트 티셔츠 · 인디고 데님" 을 읽기 전에 그림이 "멜빵 바지"를 말한다. S5(300px)·공유(920px)에선 가방·시계가 제대로 읽힌다(`10-s5`, `41-share-card`).
- 원인: `silhouette.js renderOutfit` 이 크기와 무관하게 `opts.accessories` 전부를 그림(크기 게이트 없음, `appendStage` 만 `size ≥ 240` 분기).
- **권고 정책: 카드(size < 240)는 벨트+양말만, S5·공유(≥ 240)는 전부.** 벨트·양말은 실루엣 윤곽을 바꾸지 않고(턱인·크롭일 때만 나타남) 질감만 더한다. 가방·캡·스카프·시계는 윤곽을 바꾸는 소품이라 60px 폭에서 다른 옷으로 읽힌다. 구현은 `renderOutfit` 에서 `size < 240` 이면 `accessories` 를 `group ∈ {belt, socks}` 로 필터(한 줄). S5·공유에서도 AS 요청 3(백팩 끈 z순서)과 스카프 형태(목에 감긴 느낌이 아니라 세로 띠)는 손봐야 한다.

### U6-03 (높음) 설치 배너가 뜨는 날 바로가기 줄이 있으면 배너가 하단 고정 영역 **뒤로** 들어가 "설치" 버튼이 잘림 (P1-01 의 변형)
- 실측(375, `70-s3-banner-375.png`, `73-s3-banner-pills-375.png`): 최근 2~3개 pill 줄(56px) 때문에 배너가 카드 아래로 내려감 → 배너 y **650–698**, `.bottom` top **670** → 배너 하단 28px 이 더 보기 버튼 뒤에 깔리고 설치 버튼(654–694)은 반쯤 가려짐. 본문 스크롤 646/618 = 28px 생김(홈 스크롤 0 깨짐). 360 은 pill 없이도 배너가 아래로 가며 2px 겹침(`05-s3-revisit3-coach-360.png` 는 정상인 경우).
- 왜 높음: 2회차 방문(배너 조건)에 최근 선택 2개는 흔한 조합(어제 하의, 오늘 상의). 잘린 띠가 더 보기 위에 걸쳐 보이면 고장으로 읽힌다. Phase 4 P1-01 제안 (b) "그래도 안 들어가면 **노출을 다음 방문으로 미루는 가드**"가 빠졌다.
- 제안(`s3Result.js guard()`): `banner--below` 로 내린 뒤에도 `banner.bottom > bottom.top` 이면 배너를 제거하고 `shownAt` 을 되돌려 다음 방문에 다시 시도. 또는 바로가기 줄이 있는 날은 배너를 아예 pill 줄 **안** 첫 칩(`⤓ 앱으로`)으로 접기 — 높이 0 추가.

### U6-04 (중간) "처음 안내 다시 보기"(설정·메뉴)가 S3 로 돌아올 뿐 온보딩 스트립을 보여주지 않음
- 본 것: `onboarded` 키는 지워지지만 `nav.replace('/')` → `compose` 기본 분기가 `st.base` 가 있으면 S3 를 그린다(`app.js default`). 두 진입점 모두 동일(`runD`: `main=s3, onb=false`). 다음 S3 렌더가 `onboarded=true` 를 다시 써서 영원히 못 본다.
- 제안: 기본 분기를 `st.base && read(KEYS.onboarded)` 일 때만 S3 로. 또는 안내 버튼이 `#/pick`(S1 명시 라우트)로 가고 S1 이 `recents` 를 그대로 보여주게(이미 그렇다).

### U6-05 (중간) 스타일·상황 칩 줄 2개가 360·375 에서 가로로 넘치고(아이비·격식 잘림), 상단 y 52–172 에 있으며, 이름만으로는 뜻을 모름
- 실측: 스타일 줄 scrollWidth 370 / clientWidth 328(360)·343(375), 상황 줄 368. 390 부터 들어감. 넘침 단서(그라데이션·화살표) 없음. 첫 카드는 y 184 부터.
- 3초 이해: 출근·주말·데이트·운동·산책·격식은 즉시. 미니멀·아메카지는 아는 사람만. **비즈캐주얼·아이비는 설명 없이는 모른다** — `labels.ko style.*.help` ("옥스포드·치노·페니 로퍼·네이비 블레이저")가 있는데 화면에 쓰이지 않음. 카드 라벨은 `label`("비즈니스 캐주얼", "클래식·아이비")이고 칩은 `shortLabel`("비즈캐주얼", "아이비")이라 같은 화면에서 이름이 둘(U6-13).
- 제안: ① 칩 줄을 한 줄로 합치지 말고 **두 줄 접기**(`flex-wrap`) — 스타일 4 + 상황 5 = 9칩, 두 줄씩 4행이면 y 52–260, 카드가 밀리지만 Deep 경로라 허용. 또는 상황 칩 5→3(출근·주말·데이트, ux-enhancement 7-5 원안)로 줄이면 375 한 줄에 들어간다. ② 선택된 스타일의 `help` 를 칩 줄 아래 12px 한 줄로(높이 +16). ③ Deep 1차 조작이 상단(P1-13 과 같은 문제) — 칩 줄을 탭 바 바로 위 sticky bottom 으로 내리는 안을 D1 과 검토.

### U6-06 (중간) 스타일 × 상황 교집합이 다섯에 하나 비고(19~20%), 한 장짜리 셀이 17%
