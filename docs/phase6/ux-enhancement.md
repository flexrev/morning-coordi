## 3. 오늘의 추천 (S3' — 재방문 홈)

### 3-1. 무엇이 보이나

재방문 홈은 지금처럼 **마지막 기준 아이템의 S3** 다. 거기에 두 가지만 더한다.

1. **오늘 카드**: 클래식 3장 중 날짜로 정해진 1장이 **맨 위**로 오고 라벨이 `오늘의 추천 · 클래식 2/3` 가 된다. 카드 왼쪽에 2px 앰버 세로선(`--accent`), 라벨 앞에 작은 점. 나머지 2장은 원래 라벨(`클래식 1/3`, `클래식 3/3`)·원래 순서 그대로 그 아래.
2. **상단 바 날짜**: 앱 이름 자리가 `10월 19일 · 아침 코디` (14px, 기존 `topbar__title--app`). 날짜가 바뀌었음을 알리는 유일한 장치. 인사말·날씨·느낌표 없음.

높이 변화 **0**: 라벨 줄과 세로선은 기존 카드 안. 카드 3장 y 범위는 지금(375 기준 130–572)과 같다.

왜 "맨 위로"인가: 아침에 읽는 건 첫 카드 한 장이다(P1). 세 장의 **집합은 어제와 같되 첫 장이 매일 달라지면**, 추천이 살아 있다는 느낌을 데이터·엔진 변경 없이 만든다. 카드 `ref`(`classic.N`)는 **원래 인덱스 그대로** 두므로 딥링크·즐겨찾기·S5 라벨은 영향 없음(표시 순서만 바꾼다).

### 3-2. 날짜별 결정적 회전

```
dayNumber = Math.floor((Date.now() - tzOffsetMs) / 86_400_000)      // 기기 로컬 자정 기준 일 수
seed      = fnv1a(`${base.category}|${base.color}|${season}`)        // 32-bit, 기준 아이템·계절마다 다른 출발점
todayIdx  = (dayNumber + seed) % classic.length                      // 0..2
```

- **같은 날, 같은 기준·계절이면 어느 기기에서든 같은 카드**(기기 시각이 같다면). 서버·난수 없음.
- **연속된 날은 반드시 다른 카드**(`dayNumber` 가 1 씩 증가 → 3장이면 1→2→3→1 순환). 해시만 쓰면 1/3 확률로 이틀 연속 같은 카드가 나오므로 `dayNumber` 를 더한다.
- 계절을 바꾸면 `seed` 가 바뀌어 다른 카드가 "오늘"이 된다. 기준 아이템을 바꿔도 마찬가지. 사용자가 보기에 "오늘의 추천은 기준·계절마다 하나"로 일관된다.
- 클래식이 3장 미만이거나 변주로 채운 경우(P1-18)는 `classic.length` 로 나눈다. 1장이면 그 1장(라벨은 `오늘의 추천` 만).
- 자정 넘김: 앱을 켜 둔 채 날짜가 바뀌어도 **제자리 갱신하지 않는다**(아침에 보던 카드가 갑자기 바뀌면 혼란). 다음 렌더(화면 전환·재실행)에서 반영.
- `fnv1a` 는 10줄짜리 함수(`src/ui/today.js`, 테스트 1개: 같은 입력 → 같은 출력, 연속 3일 → 서로 다른 인덱스).

### 3-3. 탭 수

| 과제 | 경로 | 탭 |
|---|---|---|
| 오늘의 추천 보기(재방문) | 실행 → S3' | **0** |
| 오늘 카드 상세 | S3' 첫 카드 → S5 | 1 |

## 4. 즐겨찾기 (♥)

### 4-1. 하트 위치

- **카드(S3·S4·F1)**: 오른쪽 위 모서리, 시각 24px 아이콘·탭 영역 **48×48**(`::after` 로 확장). 기존 `⚑` 표식은 라벨 줄 끝으로 옮긴다(라벨 `클래식 1/3 ⚑`).
- 카드는 현재 `<button class="card">` 한 덩어리라 안에 버튼을 넣을 수 없다. 구조를 `div.card > button.card__main + button.card__fav` 로 바꾼다(FE). `card__main` 이 카드 전체를 덮고, `card__fav` 는 그 위에 absolute. 오탭 방지: 하트 탭 영역 바깥 4px 은 카드 본체.
- ux-flow 4-2 가 MVP 에서 카드 안 버튼을 금지한 이유(오탭·범위)는 v1.1 에서 **범위**는 해제되고 **오탭**은 48px 단일 타깃 + 되돌릴 수 있는 토글(다시 누르면 해제)로 흡수한다.
- **S5**: 상세 칩 4줄 아래가 아니라 **하단 고정 줄**에 `♥ 저장` · `공유` 두 버튼(각 48px, 반반). S5 는 지금 하단 고정 영역이 없고 상세 4줄이 y 600–796 이라 **하단 줄 56px 을 넣으면 4번째 줄이 다시 잘린다**(P1-09 재발). 해결: `.s5__ill` 높이를 `min(36dvh, 400px)` 로 4dvh 줄인다(375 에서 −32px). 실측 재검증 필요(QA).

### 4-2. 토글 동작

- 탭 → 즉시 채워진 하트(앰버) + 하트 팝 모션(motion-spec 3-12) + 토스트 `저장했어요` 1.6초. 다시 탭 → 빈 하트 + 토스트 `저장을 해제했어요`.
- 저장 내용: `{ id: outfit.id, base, season, at }`. 같은 `id` 가 있으면 `at` 만 갱신(중복 없음).
- 30개 초과 시 가장 오래된 것을 지우고 토스트 `30개까지 저장돼요. 오래된 것을 하나 지웠어요`.
- 화면 전환 없음, 스크롤 유지, 히스토리 항목 없음.
- 햅틱: Android 만 `navigator.vibrate(10)` 1회, 저장할 때만(해제는 없음). `motion = reduce` 면 생략. iOS 는 API 가 없어 없음. 사운드는 **영구히 없음**(아침·사무실·대중교통).

### 4-3. 즐겨찾기 시트 (F1)

- 진입: ① S3 **바로가기 줄** 첫 칩 `♥ 저장 N` (즐겨찾기 ≥1 일 때만 생김) ② O2 메뉴 `즐겨찾기 N`. 바로가기 줄 = 기존 "최근 선택" 줄. 지금은 `recents > 1` 일 때만 그리는데, v1.1 은 `recents > 1 || favorites ≥ 1` 이면 그린다. 높이 48px 은 그대로(이미 예산에 있음, ui-fix-log 3절 "최근 선택까지 있으면 배너가 카드 아래로" 가드가 그대로 적용).
- 시트 안: 제목 `저장한 조합 N`, 카드 목록(S3 와 같은 컴팩트 카드, 라벨 = `하의 · 인디고 · 봄가을`, 하트는 채워진 상태). 카드 탭 → S5(`ref = fav.<id>`; `findCandidate` 에 `fav` 분기 추가 — 저장된 base·season 으로 `engine.recommend` 메모이즈 결과에서 `id` 를 찾는다. **현재 기준 아이템을 바꾸지 않는다**). 하트 탭 → 해제 + 목록에서 제거(모션: 높이 접힘 없음, 그냥 사라짐 + 토스트).
- 못 찾는 항목(데이터 버전 변경): 흐리게 + `지금 버전엔 없는 조합이에요` + 하트만 동작.
- 빈 상태(0개, O2 에서 열었을 때만 가능): `아직 저장한 조합이 없어요` + `카드의 ♥ 를 누르면 여기에 모여요` 한 줄. 버튼 없음.
- 정렬: 최신 저장순. 필터·검색 없음(30개 상한이면 스크롤로 충분).

### 4-4. 탭 수

| 과제 | 경로 | 탭 |

| 카드 저장 | S3 카드 ♥ | **1** |
| 저장 목록 열기 (저장 ≥1) | S3 바로가기 `♥ 저장 N` | **1** |
| 저장 목록 열기 (메뉴 경유) | S3 ⋯ → O2 즐겨찾기 | 2 |

## 5. 공유 카드 (SH1)

### 5-1. 흐름

```
S5 하단 [공유] ─탭▶ SH1 시트(미리보기 이미지 + 두 버튼)
   ├─ [공유하기]   → navigator.share({ files:[png], title, text })  (Web Share Level 2)
   └─ [이미지 저장] → <a download> (Android·데스크톱) / iOS standalone 은 "길게 눌러 저장" 안내
```

- 미리보기는 시트가 열리는 **동안** 캔버스에서 그린다(렌더 ≈ 30–80ms, 시트 모션 200ms 뒤에 가려짐). 그리는 동안 이미지 자리는 `--bg-2` 사각형(스켈레톤, 밝은 색 없음).
- `navigator.canShare?.({ files })` 가 false 면 `[공유하기]` 를 텍스트 공유(`{ title, text, url }`)로 바꾸고, `navigator.share` 자체가 없으면(데스크톱 Firefox 등) `[공유하기]` 를 숨기고 `[이미지 저장]` 만.
- iOS 홈 화면 앱(standalone)에서 `<a download>` 는 동작하지 않는다 → `[이미지 저장]` 대신 미리보기 아래 `이미지를 길게 눌러 저장할 수 있어요` 한 줄. `isStandalone() && isIOS()` 로 분기.
- 공유 텍스트: `화이트 티셔츠 · 인디고 데님 · 흰 스니커즈 — 아침 코디` + 딥링크 `https://flexrev.github.io/morning-coordi/#/result/bottom/indigo/outfit/classic.1` (`app.js` 가 이미 `#/result/:cat/:color/...next` 를 해석하므로 추가 라우트 없음).

## 7. 발견성

### 7-1. 무엇이 안 보이나 (현재)

- "더 보기"는 보이지만 **안에 뭐가 있는지** 모른다(톤별·색상별·변주라는 단어가 S3 어디에도 없음).
- 카드가 눌린다는 **표시가 없다**(화살표·그림자 없음). P1 검토는 "카드 탭 → S5" 를 측정했지만 처음 쓰는 사람은 모른다.
- ♥·공유·설정은 v1.1 에서 새로 생기므로 **처음 한 번** 알려줘야 한다.

### 7-2. 장치 4개 (코치마크는 평생 2개까지)

| 장치 | 어디 | 언제 | 사라짐 | 저장 |
|---|---|---|---|---|
| 더 보기 **부제** | "더 보기" 버튼 안, 글자 아래 12px `톤별 · 색상별 · 변주` (버튼 높이 56 유지, 두 줄 텍스트) | 항상 | – | – |
| 카드 **꼬리** | 카드 라벨 줄 오른쪽 끝 `자세히 ›` 12px `--text-3` (♥ 왼쪽) | 항상 | – | – |
| 코치마크 **A: 더 보기** | "더 보기" 버튼 위 말풍선 `세 장이 전부가 아니에요 — 톤별·변주는 여기에` + 꼬리 | **2회차 방문의 첫 S3**(첫 아침의 첫 결과는 깨끗하게 둔다, P1) | 아무 탭·6초·화면 전환 | `hints.more` |
| 코치마크 **B: 저장** | 첫 S5 진입 시 하단 `♥ 저장` 위 `마음에 들면 여기에 모아 두세요` | 첫 S5 | 동일 | `hints.fav` |

- 코치마크는 화면 하단 40% 안에만(P3). 상단 요소(⋯ 메뉴)에는 코치마크 없음 — 메뉴는 O2 에서 자연히 발견된다.
- 코치마크는 `role="status"` 로 읽히고, 포커스를 뺏지 않는다. 스크림 없음, 화면을 어둡게 하지 않음(P5).
- 두 개가 같은 화면에 겹칠 수 없다(A 는 S3, B 는 S5).
- 설치 배너가 보이는 날엔 코치마크 A 를 **다음 방문으로 미룬다**(한 화면에 안내 1개).

### 7-3. 메뉴 시트 (O2) — 저빈도 기능의 집

S3 상단 바: `[10월 19일 · 아침 코디]  [봄가을|여름|겨울]  [⋯]`. `⋯` 48×48. 360 폭 실측 예산: 제목 ≈ 90 + 세그먼트 ≈ 174 + ⋯ 48 + 간격 16 = 328 = 360−32 ✓. 320 폭에서는 제목을 `visually-hidden`(h1 은 유지).

O2 항목(48px 줄, 아이콘 + 글자): `♥ 즐겨찾기 N` · `⚙ 설정` · `⤓ 앱으로 두기`(미설치·모바일일 때만; 탭 → 기존 O1 시트) · `? 처음 안내 다시 보기`. 4줄 이하 고정.

### 7-4. 스타일·상황 진입점 — Deep 전용

S3 에는 넣지 않는다(Quick 불변·홈 높이 예산 0). S4 하단 탭 바에 4번째 탭 **`스타일`** 추가(`#/more/style`). 탭 4개 × 90px(360 기준) — 글자 16px 3자 이내라 들어간다. CX 데이터가 없으면 기존 패턴대로 `disabled` + "없음".

### 7-5. 7-6 데이터 계약 (CX 슬롯)

S4+ 가 기대하는 `RecommendResult` 확장. CX 의 `content-expansion.md` 9절이 다른 모양이면 **UI 가 맞춘다**(어댑터 한 함수).

```ts
result.byStyle?:    { style: 'minimal'|'amekaji'|'cityboy'|'bizcasual'|'street'|'gorpcore', candidates: Candidate[] }[]
result.byOccasion?: { occasion: 'work'|'weekend'|'date', candidates: Candidate[] }[]
candidate.tags?:    { style?: string[], occasion?: string[] }   // 카드 라벨 줄의 태그 칩(최대 2)
labels.ko: style.<id>, occasion.<id>
```

S4+ 패널: 칩 줄 2개(상단, sticky). 1줄 `스타일` 칩(있는 것만, CX 순서 고정), 2줄 `상황` 칩(출근·주말·데이트). 선택은 각 줄 **하나씩**(둘 다 고르면 교집합, 비면 `이 조합은 아직 없어요` + 상황 칩 해제 버튼). 기본 = 첫 스타일 칩, 상황 없음. 카드는 같은 컴포넌트, 라벨 = 스타일명. **S3 카드의 태그 칩**: `candidate.tags.style[0..1]` 을 라벨 줄에 `미니멀` `출근` 작은 칩(11px, `--bg-2`)으로 — 높이 0 추가(라벨 줄 안). 태그가 없으면 안 그림.

| 과제 | 경로 | 탭 |
|---|---|---|
| 스타일 보기(첫 스타일) | S3 더 보기 → S4 스타일 탭 | 2 |
| 특정 스타일 + 상황 | 위 + 스타일 칩 + 상황 칩 | 4 |

### 11-1. 톤

- **짧고 단정**: 한 문장 ≤ 20자, 명사로 끝나거나 `~요`. 두 문장이면 둘째는 동작.

## 12. 접근성

### 12-1. 포커스 순서 (S3')

`h1(날짜·앱 이름)` → 계절 세그먼트(radiogroup, 화살표로 이동) → `⋯ 메뉴` → 기준 아이템 바 → 바로가기 줄(`♥ 저장 N`, pill…) → 카드 1 본체 → 카드 1 ♥ → 카드 2 본체 → 카드 2 ♥ → 카드 3 … → 더 보기 → 카테고리 4. DOM 순서 = 시각 순서라 `tabindex` 조작 없음. ♥ 는 `aria-pressed` + `aria-label="저장, 클래식 2/3"`. 오늘 카드는 `aria-label` 앞에 `오늘의 추천.`.

### 12-2. 라이브 리전

- S3 에 `visually-hidden` `<div aria-live="polite" id="s3-live">` 1개. **제자리 갱신**(계절 토글·바로가기 pill)마다 `봄가을 조합 3개, 기준 하의 인디고` 를 써 넣는다(DOM 교체로 맥락을 잃는 스크린리더 사용자용). 전체 화면 전환(S2→S3)은 새 `main` 의 `h1` 으로 포커스를 옮기는 기존 방식 유지 — 라이브 리전과 **중복 낭독 금지**.
- 토스트는 기존 `role="status"`. 코치마크 `role="status"`, 6초 뒤 제거.
- 즐겨찾기 토글은 토스트가 낭독을 맡는다(`aria-pressed` 변화만으로 충분하지만 토스트가 있으니 이중 낭독 방지: 토스트는 `aria-live="polite"`, ♥ 는 `aria-pressed` 만).
- S5 하단 줄 `♥ 저장`·`공유` 는 일반 버튼. SH1 시트는 `role="dialog" aria-label="공유"`, 미리보기 `<img alt="{캡션} 공유 이미지">`.

### 12-3. 모션 줄이기

- 기준: `prefers-reduced-motion: reduce` **또는** `motion = reduce`. 둘 중 하나면 `html[data-motion="reduce"]`.
- 효과: 이동·크기 변화 0, 불투명도 전환만 80ms, View Transitions 호출 안 함, 스태거 0, 하트 팝 없음, 햅틱 없음, 스켈레톤 맥동 없음(정지 회색). 세부는 motion-spec 2장 "reduced 열".

### 12-4. 큰 글자 (200%)

- 브라우저 확대 200%(Chrome Android 접근성 글자 크기·데스크톱 줌)에서 카드 3장이 하단 영역과 겹친다. **컴팩트 모드**: 기존 배너 가드와 같은 rAF 측정(`cards.bottom > bottom.top`)이 참이면 `screen.classList.add('is-compact')` → 카드 일러스트 60→44px, 캡션 2줄, 이유 줄 숨김, 카드 간격 8→4. 그래도 넘치면 **스크롤 허용**(3번째 카드만 잘림, 오늘 카드는 항상 보임). 줌 감지 API 는 쓰지 않는다(불안정).
- 터치 타깃은 px 고정이라 확대 시 더 커진다(문제 없음). 칩 라벨 2줄 접기는 이미 있음(P1-10).
- 컴팩트 카드 라벨·태그 칩 11px 은 200% 에서 22px 로 커지며 라벨 줄이 두 줄로 접힐 수 있다 → 태그 칩은 `is-compact` 에서 숨김.

### 12-5. 대비·색

- ♥ 채움 = `--accent`(앰버) on `--bg-1` 4.9:1 이상, 빈 하트 = `--text-2`. 오늘 카드 세로선은 보조 신호이고 라벨 글자가 1차 신호(색만으로 구분하지 않음).
- 스크림 `--scrim` 유지. 코치마크 배경 `--bg-2` + 테두리 `--border-strong`, 글자 `--text-1`.
