1. v1 vs v2 — 코디 · 120px / 300px

왼쪽 두 개가 120px(카드 썸네일), 오른쪽 두 개가 300px(상세 시트). 각 쌍은 v1 → v2. 색·소재는 동일한 토큰·패턴 규칙으로 주입했다. 7~12번은 6-B 에 추가된 레이어(폴로·슬림·러닝·워크부츠·척카·샌들·루즈 셔츠/후디·미드 레이어)로 v1 폴백이 사라진 조합.

2. v2 레이어 카탈로그

레이어 하나씩, 기본 몸 위에. 캡션의 숫자는 path 수와 바이트. stage 레이어는 #0E0F12 위에서만 의미가 있어 검은 바탕으로 보여준다.

3. 소재 패턴 v2 — 스와치와 적용 예

소재 8종은 currentColor 저투명도 선·점이라 어떤 옷 색 위에도 얹힌다. 무늬 5종(스트라이프·핀스트라이프·깅엄·플레이드·하운드투스)은 두 번째 색이라 렌더러가 오버레이 path 에 style.color(패턴 색)를 준다 — 아래 적용 예는 화이트 티+네이비 브레통, 라이트블루 깅엄 셔츠, 차콜 핀스트라이프 하의, 버건디 버팔로 플레이드 오버셔츠, 블랙·화이트 하운드투스 블레이저. 타일은 viewBox 단위라 120px에서는 "결"로만, 300px에서 짜임이 보인다.

4. 액세서리·미드 슬롯 — 쌓임 순서 데모

z: stage → base → cap → socks → shoes → bottom → belt → top → mid → outer → scarf → bag → watch. 벨트는 상의를 clip-top-tuck(y<176)으로 넣었을 때, 양말은 바지가 crop(y<338)일 때만 드러난다. cap 슬롯은 볼캡/비니, bag 슬롯은 토트/크로스바디/백팩 중 하나.

6. 스튜디오 다크 스테이지 — stage-spotlight · stage-floor

시안 B의 카드(글래스 r22, 플레이트 92×130)와 상세(300px)를 재현. 왼쪽 카드는 시안 B 의 CSS radial-gradient 플레이트, 가운데는 stage 레이어(SVG 타원 5겹, CSS 불투명도)만, 오른쪽은 stage 레이어 + 그레인. 권장값: 120px 카드 spotlight .55 / floor .8 (blur 없음), 300px 상세 spotlight .75 + blur 6px / floor 1 + blur 3px. 스테이지는 그림 뒤(base 앞)에 들어가며 옷에는 그라데이션이 없다.
