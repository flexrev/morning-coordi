## 1. 시안 A — 에디토리얼 미니멀

**한 줄**: 패션 매거진의 한 페이지처럼. 큰 활자, 헤어라인, 매트한 어둠. 장식은 없고 비율만 있다.

### 무드
아침 여섯 시 반, 불 꺼진 방에서 보는 신문 같은 화면. 흑백에 가까운 매트 다크 위에 글자가 크고 조용하게 놓인다. 색은 옷에만 있다 — 화면 자체는 거의 무채색이라 인디고·오트밀·브라운이 그대로 "컬러"로 읽힌다. 앱이라기보다 잘 만든 룩북 한 장을 매일 받아보는 감각. "세련"을 장식의 추가가 아니라 제거로 만든다.

### 레퍼런스 포인트 (브랜드 모사 아님, 어법만)
- 남성 패션 매거진의 룩 페이지: 큰 세리프/산세리프 제목 + 작은 캡션 + 1px 괘선, 사진은 여백 안에 작게.
- 미니멀 캘린더·독서 앱의 타이포 중심 다크 UI: 상자 없이 간격과 줄로 구조를 만든다.
- 전시 캡션판: 번호(01/03) + 작품명 + 소재 — 결과 카드의 "번호 · 조합 · 이유" 구조와 같다.

### 색 시스템
| 토큰 | 값 | 대비(대 bg-0) | 비고 |
|---|---|---|---|
| `--bg-0` | `#141414` | — | 매트 베이스(현재 `#121212`에서 미세 상향, 순흑 거리 유지) |
| `--bg-1` | `#191919` | — | 일러스트 플레이트만 |
| `--bg-2` | `#222222` | — | 눌림·선택 배경 |
| `--text-1` | `#F3F1EC` | 16.9 | 본문·제목 |
| `--text-2` | `#B8B5AE` | 9.3 | 보조·칩 라벨 |
| `--text-3` | `#8F8C85` | 5.6 | 캡션·번호·아이브로우 |
| `--rule` / `--rule-strong` | `#2A2A2A` / `#3C3C3C` | — | 헤어라인 / 바닥선·입력 |
| `--ink` / `--on-ink` | `#F3F1EC` / `#141414` | 16.9 | **1차 버튼 = 반전**(액센트 색 아님) |
| `--accent` | `#D9C6A0` | 10.1 | 모래빛. 기준 아이템 링·선택 칩 체크에만 |

의류 색은 그대로. 옷이 화면에서 **유일한 채도**가 되도록 UI는 무채색 + 모래빛 한 점. 플레이트는 `--bg-1`에 1px `--rule` 안쪽 테두리 + 바닥선 1px(`--rule-strong`)로 인물이 "서 있는" 느낌만 준다. 블랙·네이비 옷은 플레이트가 bg-0보다 한 단계 밝아 분리된다(기존 규칙 유지).

### 타이포그래피
- 스택: `"Pretendard Variable", Pretendard, -apple-system, system-ui, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif`. **Pretendard Variable(SIL OFL 1.1)** woff2 서브셋 셀프호스팅 권장(≈300KB, SW precache). 폴백만으로도 성립하도록 설계.
- 위계: display 34/40 700 −0.03em(기준 아이템 "인디고 데님", S2 "하의 색은?") · 아이브로우 12/16 600 +0.10em `--text-3`("하의 · 기준 아이템") · 캡션 15/22 500 `--text-1` · 이유 13/18 `--text-2` · 번호 11 +0.14em tabular(세로 쓰기).
- 숫자는 `tabular-nums`. 한글은 `word-break: keep-all`.

### 레이아웃 언어
- **상자 없음.** 카드는 1px 헤어라인으로만 구분되는 "행". 좌우 패딩 20, 행 높이 160, 행 안 간격 16.
- 플레이트 72×136 직각(r=0) + 바닥선. 인물 60×128. 번호 "01 / 03"은 왼쪽에 세로로.
- 계절 토글은 텍스트 + 밑줄. 카테고리 줄도 텍스트 + 윗줄(활성). 1차 버튼만 면(반전).
- 간격 리듬: 4·8·12·16·20·24·48. 반경: 0~4(버튼 4, 칩 4).
- S2 칩: 64px 정사각 r=4, 4열, 라벨 13. 선택 = 흰 2px 링(offset 3). 그리드는 하단 정렬, 상단은 큰 제목 + 보조문으로 채움.

### 질감·깊이
그레인 없음, 그림자 없음, 글래스 없음. 깊이는 **헤어라인 2종(`--rule`, `--rule-strong`)과 bg 2단**으로만. 옷에 그라데이션 없음.

### 모션 언어 (5줄)
1. 움직이는 것: 카드 행(12px 상승 + 페이드), 헤어라인(왼쪽→오른쪽 그려짐), 칩 눌림.
2. 이징: `cubic-bezier(.2,.8,.2,1)` 하나만. 스프링 없음.
3. 길이: 행 360ms, 간격 70ms(3장 총 ≤ 500ms), 헤어라인 420ms, 눌림 120ms.
4. 절대 안 움직이는 것: 글자(위치·크기), 실루엣, 기준 아이템 바, 하단 고정 영역.
5. `prefers-reduced-motion`: 전부 0. 화면 전환은 View Transitions의 크로스페이드만(200ms).

### S1 / S2 / S3 변화
- **S1**: "오늘 뭐 입지?" display 34 한 줄 + 2×2 카테고리 버튼을 **텍스트 + 헤어라인 격자**로(면 없음). 최근 선택은 행 리스트.
- **S2**: 상단 아이브로우("둘 중 두 번째") + display 제목 + 보조문. 칩 정사각 r=4, 하단 정렬 유지. 2탭 흐름 불변.
- **S3**: 기준 아이템 바 → **히어로 타이틀**("인디고 데님" 34px + 색 사각 스와치 + "색 바꾸기 ›"). 카드 3행 헤어라인. 더 보기 = 반전 버튼. 카테고리 = 텍스트 탭.

## 2. 시안 B — 스튜디오 다크

**한 줄**: 촬영 스튜디오의 어둠. 인물에만 부드러운 조명이 떨어지고, 유리 같은 표면 위에 앰버 한 점.

### 무드
어두운 스튜디오에서 모델이 조명 아래 서 있는 장면을 카드 크기로 압축한다. 배경은 푸른기 섞인 깊은 차콜, 좌상단에서 아주 옅은 아침빛이 들어온다. 카드는 반투명 유리판처럼 배경 위에 떠 있고, 각 카드의 인물 뒤에는 타원형 스포트라이트와 바닥 그림자가 있어 평면 실루엣이 "서 있는 사람"으로 읽힌다. 화면 전체에 7% 그레인이 깔려 디지털 평면이 아니라 필름 같은 질감. 앰버는 아침 해 — 기준 아이템 링, 라벨 점, 더 보기 버튼에만 켜진다. 현재 MVP의 다크·앰버 혈통을 유지하면서 가장 "다이나믹"한 안.

### 레퍼런스 포인트
- 패션 룩북 스튜디오 촬영의 그레이 배경 + 탑라이트: 인물 주변만 밝고 가장자리는 어둠으로 녹는다.
- 최근 모바일 OS의 반투명 머티리얼(블러 + 1px 하이라이트 테두리): 표면이 배경 위에 "떠 있다"는 신호.
- 필름 그레인·다크룸 포토 앱: 미세 노이즈가 순흑 밴딩을 숨기고 깊이를 만든다.

### 색 시스템
| 토큰 | 값 | 대비(대 bg-0) | 비고 |
|---|---|---|---|
| `--bg-0` | `#0E0F12` | — | 깊은 차콜, 푸른기 1단계 |
| `--bg-1` | `rgba(255,255,255,.045)` + `backdrop-filter: blur(14px)` | — | 글래스 카드. 미지원 폴백 `#1A1B1F` |
| `--bg-2` | `rgba(255,255,255,.08)` | — | 눌림·선택 |
| `--glass-border` / `--glass-hi` | `rgba(255,255,255,.09)` / `.16` | — | 테두리 / 상단 1px 하이라이트 |
| `--text-1` | `#F4F2ED` | 18.2 | 본문 |
| `--text-2` | `#B9B6AF` | 9.6 | 보조 |
| `--text-3` | `#8E8B85` | 5.6 | 캡션 |
| `--accent` | `#E8B964` | 10.9 | 앰버(현 `#E0BE7E`보다 살짝 따뜻·진함). 글자로 써도 OK |
| `--accent-glow` | `rgba(232,185,100,.28)` | — | 링·버튼 글로우 |
| `--spot` | `rgba(255,230,190,.17)` | — | 스포트라이트 중심(따뜻한 백색) |

**옷 색과의 관계**: 스포트라이트는 인물 **뒤** 플레이트에만 있고 실루엣 fill은 단색 그대로다(그라데이션은 배경·조명에만, 원칙 유지). 밝은 옷(화이트·오트밀)은 스포트라이트 중심에서 살짝 더 떠 보이고, 어두운 옷(네이비·블랙)은 플레이트의 `rgba(0,0,0,.28)` 바닥과 `drop-shadow`로 분리된다. 글래스 위 본문은 실질 배경이 `#1A1B1F` 수준이라 `--text-1` 대비 ≥ 15:1.

### 타이포그래피
- 스택: A와 동일(Pretendard Variable, OFL). 굵기만 더 쓴다 — 제목 800, 캡션 600.
- 위계: 제목 30/38 800 −0.025em · 기준 아이템 17/22 700 · 아이브로우 11 +0.12em 700 **앰버**("클래식 01", "하의 · 기준") · 캡션 15/22 600 · 이유 13/18.
- 번호는 두 자리("01·02·03") tabular.

### 레이아웃 언어
- 카드 r=22, 글래스, 높이 150, 간격 10. 플레이트 92×130 r=16, 내부에 스포트라이트 + 바닥 그림자(blur 4px 타원). 인물 66×132 + `drop-shadow`.
- 기준 아이템 바 = 글래스 필(r=20, 64px) + 36px 원형 칩에 앰버 링·글로우.
- 계절 토글 = 글래스 필 + 앰버 썸. 카테고리 = 글래스 세그먼트(48px 버튼).
- 간격 리듬: 4·8·10·14·20·28. 반경: 12·16·18·20·22·999.
- S2 칩: 62px r=20(스쿼클 느낌), 상단 1px 하이라이트 + 바닥 그림자. 선택 = 앰버 2px 링 + 글로우. 4열, 하단 정렬.

### 질감·깊이
- **그레인**: 인라인 SVG `feTurbulence`(외부 파일 없음) 7%, `mix-blend-mode: overlay`, 화면 전체.
- **글래스**: `backdrop-filter: blur(14px)` + 1px 테두리 + 상단 하이라이트. `@supports not` 폴백 단색.
- **조명**: 좌상단 아침빛(radial 11%), 플레이트 스포트라이트(radial 17%), 바닥 그림자. 옷에는 그라데이션 없음.
- 그림자는 앰버 버튼 글로우(`0 10px 30px`)와 인물 drop-shadow 2곳만.

### 모션 언어 (5줄)
1. 움직이는 것: 기준 바·카드(16px 상승 + scale .97→1 + 페이드), **스포트라이트가 켜짐**(opacity 0→1), 칩 팝인, 토글 썸 이동, 1차 버튼 글로우 수축.
2. 이징: 등장 `cubic-bezier(.2,.8,.2,1)`, 칩 눌림만 `cubic-bezier(.34,1.3,.5,1)` 스프링.
3. 길이: 카드 420ms · 간격 80ms(3장 ≤ 580ms) · 조명 600ms(카드보다 늦게 켜져 "불이 들어오는" 순서) · 칩 260ms · 눌림 120ms · 토글 200ms.
4. 절대 안 움직이는 것: 실루엣(위치·스케일·회전 금지), 그레인(고정, 애니메이션 금지 — 배터리·멀미), 글자, 하단 고정 영역. 루프 애니메이션 없음.
5. `prefers-reduced-motion`: 전부 0, 글로우는 정적 유지. 저사양: `backdrop-filter`를 끄는 `data-perf="low"` 스위치(QA 게이트 6).

### S1 / S2 / S3 변화
- **S1**: 좌상단 아침빛 + "오늘 뭐 입지?" 30px 800. 2×2 카테고리는 글래스 타일(72px), 탭 시 앰버 링. 최근 선택은 글래스 필 3개.
- **S2**: 앰버 아이브로우 "2 / 2 · 색 고르기" + 제목 30px + 보조문. 칩 62 r=20, 선택 앰버 링+글로우, 눌림 스프링. 하단 정렬 유지.
- **S3**: 기준 아이템 바 = 글래스 필(앰버 링 칩 + "하의 · 기준 / 인디고 데님" + "바꾸기 ›"). 카드 3장 글래스 + 스포트라이트 플레이트 + 앰버 "클래식 01" 라벨. 더 보기 = 앰버 글로우 버튼. 카테고리 = 글래스 세그먼트.

## 3. 시안 C — 소프트 라이트

**한 줄**: 따뜻한 종이 위의 옷 스케치. 라이트 우선, 어스 액센트, 다크는 2차 테마.

### 무드
커튼 사이로 빛이 들어오는 아침. 오프화이트 종이 질감 위에 둥근 카드가 한 장씩 놓이고, 히어로 한 줄만 세리프로 "오늘은 인디고 데님."이라고 말을 건다. 액센트는 흙·점토(클레이)와 세이지 — 옷 색(어스톤·네이비·뉴트럴)과 같은 세계의 색이라 UI와 옷이 한 팔레트로 읽힌다. 옷 색이 **가장 정확하게 보이는 안**(흰 티·오트밀·베이지가 다크 배경에서 떠 보이지 않음). 대신 "어두운 방" 원칙과 충돌하므로 다크 변형을 반드시 같이 들고 간다(시안 파일의 체크박스).

### 레퍼런스 포인트
- 종이 스케치북·패브릭 스와치 북: 질감 있는 오프화이트, 스와치는 그림자가 있는 실물처럼.
- 웰니스·일기 앱의 따뜻한 라이트 UI: 둥근 모서리, 낮은 채도 어스 액센트, 세리프 한 줄.
- 남성복 편집숍의 룩 카드: 종이 라벨 + 손글씨 느낌의 제목 + 간결한 소재 표기.

**옷 색과의 관계**: 라이트에서는 흰색 계열 칩/실루엣이 카드와 붙으므로 `--chip-border` 검정 14% + 플레이트 `--bg-2`(한 톤 어두운 종이)로 분리. 플레이트 바닥에 갈색 기운 그림자 타원. 의류 색 토큰은 테마와 무관하게 고정.

### 타이포그래피
- 본문: Pretendard Variable(OFL). **히어로·S2 제목 한 줄만** `Noto Serif KR`(SIL OFL 1.1, 가변 woff2 서브셋 셀프호스팅 ≈ 400KB — 한 굵기(600)만 서브셋하면 ≈ 150KB). 폴백 `"Apple Myungjo", "Nanum Myeongjo", Batang, serif`.
- 위계: 히어로 세리프 24/30 600("오늘은 인디고 데님.") · S2 제목 세리프 30/38 · 캡션 15/22 600 · 이유 13/18 · 라벨 11 700 클레이 필.
- 세리프는 두 곳 이상 쓰지 않는다(장식이 아니라 "말 걸기" 신호).

### 레이아웃 언어
- 카드 r=22 흰 종이 + 부드러운 갈색 그림자, 높이 150, 간격 12. 플레이트 92×130 r=16 `--bg-2` + 바닥 그림자. 인물 66×132.
- 히어로 = 44px r=14 스와치 + 세리프 한 줄 + 보조 한 줄 + "색 바꾸기 ›"(클레이).
- 라벨 "클래식 1"은 클레이 소프트 필(pill). 계절 토글 = 흰 필 + 그림자. 카테고리 = 흰 필 4개, 활성은 클레이 소프트 + 1.5px 링.
- 간격 리듬: 4·8·12·14·20·28. 반경: 14·16·18·22·999.
- S2 칩: 62px r=18 + 그림자(실물 스와치), 선택 = 클레이 2px 링. 4열, 하단 정렬.

### 질감·깊이
- **종이**: 인라인 SVG `feTurbulence` 4.5% `multiply`(다크에선 6% `overlay`).
- **그림자 2단**(갈색 기운) — 라이트는 그림자로, 다크는 bg 단계로 높이 표현(기존 원칙과 동일).
- 글래스·그레인·조명 없음. 옷에 그라데이션 없음.

### 모션 언어 (5줄)
1. 움직이는 것: 히어로 한 줄 페이드, 카드(14px 상승 + 페이드 + **그림자가 뒤늦게 자리잡음**), 칩 눌림(scale .96 + 그림자 사라짐 = "눌린 종이"), 카테고리 필 배경색.
2. 이징: `cubic-bezier(.2,.8,.2,1)`, 그림자는 `ease-out`.
3. 길이: 카드 320ms · 간격 70ms · 그림자 500ms · 눌림 120ms · 필 160ms.
4. 절대 안 움직이는 것: 실루엣, 종이 질감, 글자, 하단 고정 영역.
5. `prefers-reduced-motion`: 전부 0. 테마 전환은 200ms 배경 페이드만(reduced면 즉시).

### S1 / S2 / S3 변화
- **S1**: 세리프 "오늘, 뭐 입을까요?" + 2×2 흰 종이 타일(72px, 그림자), 탭 시 클레이 링. 최근 선택은 흰 필.
- **S2**: 클레이 아이브로우 + 세리프 제목 + 보조문. 칩은 실물 스와치처럼 그림자. 하단 정렬 유지.
- **S3**: 기준 아이템 바 → **세리프 히어로**("오늘은 인디고 데님." + "하의 기준 · 클래식 조합 3가지"). 카드 3장 흰 종이. 더 보기 = 클레이 버튼. 카테고리 = 흰 필.

## 5. 권고

**B 스튜디오 다크를 기본안으로, A의 타이포 위계를 가져온다.**

이유
1. 오너가 요구한 세 단어(세련·모던·**다이나믹**) 중 "다이나믹"을 정적인 CSS로 만들 수 있는 안은 B뿐이다. 조명이 켜지고 유리판이 떠오르는 순서 자체가 모션 언어가 된다 — 실루엣을 한 픽셀도 움직이지 않으면서.
2. 불변 원칙과 가장 잘 맞는다. 다크 기본·앰버 액센트·실루엣 단색 fill·옷 색 고정을 전부 유지하고 **값만 조정**한다(bg `#121212→#0E0F12`, 앰버 `#E0BE7E→#E8B964`). AS 팀 자산 v2(음영·디테일 선)는 스포트라이트 플레이트 위에서 가장 잘 산다.
3. 확장 축(아키타입·상황)에 "조명 색온도"라는 표현 수단이 하나 더 생긴다. 옷 색을 건드리지 않고 분위기를 바꿀 수 있는 유일한 레버다.
4. 비용은 중간이지만 통제 가능: 글래스는 카드 3장 + 바 2개로 제한, `@supports` 폴백, 저사양 스위치. 그레인은 data-URI 1개(≈ 600B).

A에서 가져올 것: 기준 아이템을 **히어로 타이틀급**으로 키우는 위계, 아이브로우(작고 자간 넓은 라벨) 체계, 액센트를 3곳으로 제한하는 규율. C에서 가져올 것: 라이트 테마가 필요해질 때의 갈색 기운 그림자와 종이 톤 `#F3EFE6`(현재 라이트 토큰 `#F6F5F1` 대체 후보).

채택 시 다음 단계(6-B 입력)
- 토큰 v2 표(B 열) → `src/styles/tokens.css` 교체안
- 플레이트 컴포넌트 스펙(스포트라이트·바닥 그림자·drop-shadow 값, 60/92/160px 3사이즈)
- 모션 스펙은 UX 팀 `motion-spec.md`와 합치되 위 "5줄"을 상한으로
- QA: backdrop-filter 폴백 스크린샷, OLED 그레인 밝기, Lighthouse ≥ 95, reduced-motion

## 6. 검증 메모 (시안 파일)

- 세 시안 모두 S3·S2 화면이 844px 안에 스크롤 없이 들어감(측정: `.screen` scrollHeight = clientHeight = 844).
- 터치 타깃: 칩 ≥ 80×88(라벨 포함), 계절 토글 48(`::after` 확장), 카테고리 48, 1차 버튼 56, 카드 전체 ≥ 150.
