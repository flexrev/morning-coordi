## 3. 구현 중 내린 결정

- **카드 일러스트 소품 정책**: 카드(<240px)는 벨트·양말만, 상세·공유는 토트·크로스바디·시계·캡·스카프까지. **백팩은 어느 크기에서도 그리지 않음**(목걸이·멜빵으로 오독) — 텍스트 칩만
- **오늘의 추천 라벨**: "오늘의 추천" / "다른 클래식 1/2·2/2". 상세·공유 제목 "오늘의 추천 · 봄가을"
- **설치 배너**: 카드 3장과 함께 안 들어가면 다음 방문으로 미룸(겹침·스크롤 금지)
- **상황 칩 축소**: 출근·주말·데이트 + "더"(운동·격식). 스타일×상황은 엔진 직접 호출, 부족 시 `shortfall` 안내 문구
- **격식·운동 상황**: 거리 비례 감점, 완화 상한 stage 2 → 3장 미만 허용(부족 안내). 운동은 울 하의를 저지·나일론으로 재구체화
- **스타일 그룹**: 태그 포함 카드만, 그룹 간 겹침 ≤ 2. 오태그 7→1
- **번들 분할**: 핵심 데이터 즉시, 확장 데이터는 첫 페인트 뒤 idle에 적재. v1 실루엣 삭제. workbox-window 제거(직접 등록)
- **그레인 제거**(120px에서 식별 불가), 코치마크 B 제거, 스타일 태그 칩은 3장이 다를 때만
- **캡션 어휘 통일**: 카드·상세·공유 모두 `catalog.cardName`
