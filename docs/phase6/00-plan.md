# Phase 6 — 미적 고도화 · 자산 개발 · 추천 확장

작성일: 2026-10-19 · 기준: MVP 1.0-rc (https://flexrev.github.io/morning-coordi/)

## 1. 목표

| 축 | 현재 | 목표 |
|---|---|---|
| 비주얼 | 기능 위주 다크 UI, 단색 실루엣 | 세련되고 모던한 에디토리얼 감성. 깊이·질감·타이포 위계가 있는 프로페셔널 룩 |
| 모션 | 전환 효과 없음 | 화면 전환·카드 등장·칩 선택에 의미 있는 모션. 다이나믹하되 아침 10초 원칙을 해치지 않음 |
| 자산 | SVG 실루엣 27개, 단색 fill | 자산 시스템 v2: 품목 확대, 음영·질감·디테일 선, 히어로 그래픽, 아이콘 세트. 전부 자체 제작·라이선스 걱정 없음 |
| 추천 폭 | 색 베이스 1개 → 클래식 3 + 톤/색상/변주 | 스타일 아키타입(미니멀·아메카지·시티보이·비즈캐주얼·스트릿·고프코어), 상황(출근·주말·데이트), 액세서리·패턴·레이어링까지 확장 가능한 데이터·엔진 구조 |
| UX | Quick/Deep 2경로 | 오늘의 추천, 즐겨찾기, 공유 카드, 온보딩, 발견성 강화. Quick 2탭은 불변 |

**불변 원칙**: Quick 경로 2탭·10초, 오프라인, 번들 예산(gzip JS ≤ 120KB로 상향, Lighthouse 성능 ≥ 95), `prefers-reduced-motion` 존중, 외부 이미지·폰트 CDN 금지(셀프호스팅은 허용).

## 3. 단계

```
6-A 컨셉·탐색 (병렬 4: AD ∥ AS ∥ CX ∥ UX)
   게이트 5: 시안 2~3안 중 사용자가 1안 선택 · 자산 v2 프로토타입 가독성 · 확장 스키마 확정
6-B 구현 (AS 자산 제작 ∥ CX 데이터·엔진 확장 → FE 화면 리뉴얼·모션 → QA)
   게이트 6: Quick 2탭 유지 · Lighthouse ≥95 · reduced-motion · 콘텐츠 재확인 4기준 PASS
6-C 배포 → MVP 1.1
```

## 4. 결정 필요 (사용자)

1. 비주얼 방향 — 6-A 시안 보고 선택
2. 스타일 아키타입 1차 범위 — CX 제안 중 MVP 1.1에 넣을 3~4개
3. 사진/실사 자산 도입 여부 — 기본안은 "자체 제작 벡터만"(라이선스·용량·일관성). 실사는 2차 검토
